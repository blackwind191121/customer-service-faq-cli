# Customer Service FAQ CLI

這是一個使用 Python 開發的命令列客服 FAQ 管理系統，支援 FAQ 查詢、新增、刪除，以及以 JSON 儲存與管理 FAQ 資料。

V1 採用規則式的關鍵字權重比對，不使用 AI，主要用來實作 Python 基礎程式設計、模組拆分、檔案讀寫與基本 CRUD 流程，後續版本預計逐步加入 API、網頁介面、資料庫與 RAG。

This is a command-line customer service FAQ management system developed in Python, which supports querying, adding and deleting FAQs, as well as storing and managing FAQ data in JSON format.

Version 1 utilises rule-based keyword weight matching without the use of AI. It is primarily intended to demonstrate fundamental Python programming, module separation, file I/O and basic CRUD operations. Subsequent versions are expected to gradually incorporate APIs, a web interface, a database and RAG.
